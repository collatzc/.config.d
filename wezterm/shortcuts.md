# WezTerm 快捷键清单(macOS)

> 前缀键(Leader)为 **⌘P**:先按 ⌘P,1 秒内再按后续键。
> 标 ⭐ 的是 `~/.wezterm.lua` 中自定义的键位,其余为 WezTerm 默认。

## 常用:分屏与面板

| 快捷键 | 功能 |
| --- | --- |
| ⌘D | 左右分屏 ⭐ |
| ⌘⇧D | 上下分屏 ⭐ |
| ⌘↩ | 上下分屏(与 ⌘⇧D 等效)⭐ |
| ⌘⌥ ←/→/↑/↓ | 切换面板焦点 ⭐ |
| ⌘⇧↩ | 面板最大化 / 还原(zoom)⭐ |
| ⌘P x | 关闭当前面板(有确认)⭐ |
| ⌘W | 关闭当前标签页 |

## 标签页

| 快捷键 | 功能 |
| --- | --- |
| ⌘T | 新建标签页 |
| ⌘W | 关闭标签页(有确认) |
| ⌘N | 新建窗口 |
| ⌘1 ~ ⌘8 | 跳到第 1–8 个标签页 |
| ⌘9 | 跳到最后一个标签页 |
| ⌘⇧[ / ⌘⇧] | 上一个 / 下一个标签页 |
| ⌃Tab | 切回上一个使用的标签页 ⭐ |

## 外观

| 快捷键 | 功能 |
| --- | --- |
| ⌘P t | 明暗配色切换(Tokyo Night)⭐ |
| ⌃⌘F | 原生全屏(跟随系统样式) |
| ⌘+ / ⌘- / ⌘0 | 放大 / 缩小 / 重置字号 |

## 剪贴板、搜索与选择

| 快捷键 | 功能 |
| --- | --- |
| ⌘C / ⌘V | 复制 / 粘贴(鼠标选中即自动复制) |
| ⌘F | 在回滚缓冲区中搜索 |
| ⌃⇧Space | QuickSelect:快速抓取屏幕上的 URL、路径、哈希 |
| ⌃⇧X | Copy Mode(vim 式键位:空格开始选择,y 复制,q 退出) |
| ⌃⇧U | emoji / 特殊字符选择器 |
| ⌘K | 清屏并清空回滚缓冲区 |

## 窗口与应用(macOS 标准)

| 快捷键 | 功能 |
| --- | --- |
| ⌘M | 最小化窗口 |
| ⌘H | 隐藏应用 |
| ⌘Q | 退出 WezTerm |

## 杂项

| 快捷键 | 功能 |
| --- | --- |
| ⌃⇧P | 命令面板(可搜索并执行所有动作) |
| ⌘R | 重新加载配置 |
| ⌃⇧L | 调试面板(查看日志) |
| ⌘ + 拖拽标题栏 | 任意位置拖动窗口 ⭐ |

## 鼠标

| 操作 | 功能 |
| --- | --- |
| 选中文本 | 自动复制到剪贴板 |
| ⌘V | 粘贴 |
| 点击 URL | 用默认浏览器打开 |
| ⌘ + 拖拽 | 拖动窗口 |
